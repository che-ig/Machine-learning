````markdown
## Задания для практики

### Уровень 1: Базовые операции

**Задание 1.1** — Выведите имена всех сотрудников из `employees.csv` (2-е поле).

<details>
<summary>Подсказка</summary>

```bash
awk -F, 'NR>1 {print $2}' employees.csv
```
</details>

---

**Задание 1.2** — Выведите IP-адреса из `access.log` (первое поле).

<details>
<summary>Подсказка</summary>

```bash
awk '{print $1}' access.log
```
</details>

---

**Задание 1.3** — Выведите только строки из `users.txt`, где shell — `/bin/bash`.

<details>
<summary>Подсказка</summary>

```bash
awk -F: '$7 == "/bin/bash"' users.txt
```
</details>

---

**Задание 1.4** — Посчитайте количество строк в `numbers.txt`.

<details>
<summary>Подсказка</summary>

```bash
awk 'END {print NR}' numbers.txt
```
</details>

---

**Задание 1.5** — Выведите все пустые строки из `mixed.txt` с их номерами.

<details>
<summary>Подсказка</summary>

```bash
awk 'NF==0 {print NR": [пустая строка]"}' mixed.txt
```
</details>

<details>
<summary>Подсказка</summary>

awk -F, 'NR>1 && $4 > 100000 {print $2, $4}' employees.csv

**Задание 2.4** — Выведите из `employees.csv` сотрудников из IT-отдела, которые работают в Москве.

**Задание 2.5** — Выведите из `access.log` строки с диапазона по шаблону: от первого `403` до первого `200` после него.

### Уровень 3: Математика и статистика

**Задание 3.1** — Посчитайте общую сумму зарплат в `employees.csv`.

<details>
<summary>Подсказка</summary>

```bash
awk -F, 'NR>1 {sum += $4} END {print "Общий ФОТ:", sum}' employees.csv
```
</details>

---

**Задание 3.2** — Найдите минимальную и максимальную зарплату в `employees.csv`.

<details>
<summary>Подсказка</summary>

```bash
awk -F, 'NR==2 {min=$4; max=$4} 
         NR>2 {if($4<min) min=$4; if($4>max) max=$4} 
         END {print "Min:", min, "Max:", max}' employees.csv
```
</details>

---

**Задание 3.3** — Посчитайте сумму продаж по каждому товару из `sales.txt` (количество × цена).

<details>
<summary>Подсказка</summary>

```bash
awk '{sum[$2] += $3 * $4} END {for (item in sum) print item, sum[item]}' sales.txt
```
</details>

---

**Задание 3.4** — Найдите среднее, минимальное и максимальное значение в `numbers.txt`.

<details>
<summary>Подсказка</summary>

```bash
awk 'NR==1 {min=$1; max=$1} 
     {sum+=$1; if($1<min) min=$1; if($1>max) max=$1} 
     END {print "Avg:", sum/NR, "Min:", min, "Max:", max}' numbers.txt
```
</details>

---

**Задание 3.5** — Посчитайте общую выручку по датам из `sales.txt`.

<details>
<summary>Подсказка</summary>

```bash
awk '{sum[$1] += $3 * $4} END {for (d in sum) print d, sum[d]}' sales.txt | sort
```
</details>

### Уровень 4: Ассоциативные массивы и группировка

**Задание 4.1** — Подсчитайте количество сотрудников в каждом отделе из `employees.csv`.

<details>
<summary>Подсказка</summary>

```bash
awk -F, 'NR>1 {count[$3]++} END {for (d in count) print d, count[d]}' employees.csv
```
</details>

**Задание 4.2** — Подсчитайте количество запросов с каждого IP из `access.log` и отсортируйте по убыванию.

<details>
<summary>Подсказка</summary>

```bash
awk '{count[$1]++} END {for (ip in count) print count[ip], ip}' access.log | sort -rn
```
</details>

**Задание 4.3** — Подсчитайте количество запросов по каждому HTTP-статусу из `access.log`.

<details>
<summary>Подсказка</summary>

```bash
awk '{status[$9]++} END {for (s in status) print s, status[s]}' access.log
```
</details>

---

**Задание 4.4** — Выведите только дубликаты строк из `duplicates.txt`.

<details>
<summary>Подсказка</summary>

```bash

```
</details>

**Задание 4.5** — Выведите только уникальные строки из `duplicates.txt` (первые вхождения).

<details>
<summary>Подсказка</summary>

```bash
awk '!a[$0]++' duplicates.txt
```
</details>

---

**Задание 4.6** — Подсчитайте среднюю зарплату по каждому отделу из `employees.csv`.

<details>
<summary>Подсказка</summary>

```bash

**Задание 5.1** — Выведите из `config.ini` все секции, где `enabled=true`.

**Задание 5.2** — Из `config.ini` извлеките host и port только для серверов из региона `moscow`.

<details>
<summary>Подсказка</summary>

```bash
awk -v RS='' '/region=moscow/ {
    for (i=1; i<=NF; i++) {
        if ($i ~ /^host=/) host=$i
        if ($i ~ /^port=/) port=$i
    }
    print host, port
}' config.ini
```
</details>

---

**Задание 5.3** — Объедините данные: для каждого сотрудника из `employees.csv` выведите его имя и город, отформатированные в колонки.

<details>
<summary>Подсказка</summary>

```bash
awk -F, 'NR>1 {printf "%-20s | %-15s | %8d\n", $2, $5, $4}' employees.csv
```
</details>

**Задание 5.4** — Найдите в `access.log` IP-адреса, которые получили ошибку 403 более одного раза.

<details>

</details>

**Задание 5.5** — Из `mixed.txt` выведите только строки, где заполнены все 4 поля (ID, Name, Age, City).

**Задание 5.6** — Посчитайте, сколько сотрудников было нанято в каждом году из `employees.csv`.

<details>
<summary>Подсказка</summary>

```
</details>

**Задание 5.7** — Объедините `employees.csv` и `sales.txt`: найдите, сколько продаж пришлось на Москву (по городу из `employees.csv` — но это сложно, упростим: просто выведите общую сумму продаж и общую сумму зарплат в одном выводе).

<details>
<summary>Подсказка</summary>

```bash
awk -F, 'NR>1 {salary_sum += $4} END {print "ФОТ:", salary_sum}' employees.csv
awk '{sales_sum += $3 * $4} END {print "Продажи:", sales_sum}' sales.txt
```
</details>

---

**Задание 5.8** — Создайте отчёт: для каждого отдела из `employees.csv` выведите количество сотрудников, общую и среднюю зарплату, отформатированные в таблицу.

<details>
<summary>Подсказка</summary>

```bash
awk -F, 'NR>1 {
    count[$3]++
    sum[$3] += $4
}
END {
    printf "%-12s | %10s | %12s | %12s\n", "Department", "Count", "Total", "Average"
    printf "%-12s-+-%10s-+-%12s-+-%12s\n", "------------", "----------", "------------", "------------"
    for (d in count) {
        printf "%-12s | %10d | %12d | %12.2f\n", d, count[d], sum[d], sum[d]/count[d]
    }
}' employees.csv
```
</details>

## Чек-лист для самопроверки

После выполнения заданий убедитесь, что вы умеете:

- [ ] Использовать `-F` и `FS` для разных разделителей
- [ ] Использовать `OFS` для изменения выходного разделителя
- [ ] Работать с `NR`, `NF`, `FNR`, `FILENAME`
- [ ] Использовать `BEGIN` и `END` блоки
- [ ] Фильтровать строки по условиям и регулярным выражениям
- [ ] Использовать диапазонные шаблоны (`/start/,/end/`)
- [ ] Считать суммы, средние, минимумы, максимумы
- [ ] Использовать ассоциативные массивы для группировки
- [ ] Использовать `a[$0]++` и `!a[$0]++` для дубликатов/уникальных
- [ ] Использовать `printf` для форматированного вывода
- [ ] Работать с режимом абзацев (`RS=''`)
- [ ] Использовать функции `split`, `substr`, `gsub`
- [ ] Передавать переменные через `-v`
````
