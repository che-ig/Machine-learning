# Подробное руководство по утилите AWK

## 1. Введение: Что такое AWK?

AWK — это интерпретируемый язык программирования, предназначенный для обработки текстовых данных и генерации отчетов. Название образовано из первых букв фамилий его создателей: Альфред **А**хо, Питер **В**ейнбергер и Брайан **К**ерниган.

Ключевая парадигма AWK — **данные, управляемые шаблонами (pattern-action)**. Программа на AWK читает входной поток данных (файл или стандартный ввод) построчно. Каждая строка сравнивается с набором шаблонов. При совпадении выполняется соответствующее шаблону действие.

AWK идеально подходит для:

- Извлечения и форматирования полей в текстовых файлах (CSV, логи, вывод команд).
    
- Арифметических и строковых операций над данными.
    
- Генерации структурированных отчетов из неструктурированных данных.
    
- Прототипирования сложных скриптов, которые позже можно переписать на других языках.
    

Наиболее распространенная реализация в Linux — **GNU Awk (gawk)**.

## 2. Базовый синтаксис и запуск

Общий синтаксис вызова `awk` из командной строки:

bash

awk [опции] 'программа' [файл ...]

или для чтения программы из файла:

bash

awk -f файл_скрипта [файл ...]

Если файл не указан, AWK читает данные из стандартного ввода (`stdin`).

**Пример 1: минимальная программа**

bash

awk '{ print $0 }' /etc/passwd

Эта команда выводит каждую строку файла `/etc/passwd` целиком. Действие `print $0` печатает текущую строку (всю строку). Поскольку шаблон отсутствует, действие выполняется для каждой строки.

**Пример 2: вывод только строк, содержащих слово "root"**

bash

awk '/root/ { print $0 }' /etc/passwd

Здесь шаблон `/root/` — регулярное выражение, которое ищет подстроку "root" в строке.

**Пример 3: работа со стандартным вводом**

bash

ls -l | awk '{ print $5, $9 }'

Вывод команды `ls -l` передается в AWK, который печатает 5-е поле (размер) и 9-е поле (имя файла).

## 3. Структура программы AWK

Программа AWK состоит из последовательности **правил** вида:

text

шаблон { действие }

Правила выполняются последовательно для каждой входной строки. Возможны варианты:

- `{ действие }` — действие выполняется для всех строк (шаблон по умолчанию — истина).
    
- `шаблон` — если шаблон истинен, то выполняется действие по умолчанию — `print $0`.
    
- `шаблон { действие }` — полная форма.
    
- `BEGIN { действие }` — действие выполняется **до** чтения первой строки входного файла.
    
- `END { действие }` — действие выполняется **после** обработки всех строк.
    

**Пример 4: использование BEGIN и END**

bash

awk 'BEGIN { print "Начало отчета" } { print $0 } END { print "Конец отчета" }' /etc/passwd

Сначала печатается "Начало отчета", затем каждая строка файла, затем "Конец отчета".

**Пример 5: несколько правил**

bash

awk '/^root/ { print "Найден root: " $0 } /^daemon/ { print "Найден daemon: " $0 }' /etc/passwd

## 4. Поля и разделители

AWK автоматически разбивает каждую входную строку на **поля** (fields). По умолчанию поля разделены **пробелами** (одним или более) или символами табуляции. К полям обращаются через `$1`, `$2`, ... `$NF` (последнее поле). `$0` означает всю строку.

**Разделитель полей на входе** задается встроенной переменной `FS` (Field Separator). Его можно установить:

- Опцией `-F` в командной строке: `-F:`
    
- Присвоив `FS` в программе: `BEGIN { FS = ":" }`
    
- Используя переменную окружения `AWKFS` (не рекомендуется).
    

**Пример 6: смена разделителя полей**

bash

awk -F: '{ print $1, $3 }' /etc/passwd

Выводит имя пользователя и UID из файла паролей (поля разделены двоеточием).

**Пример 7: задание разделителя внутри программы**

bash

awk 'BEGIN { FS = ":" } { print $1 }' /etc/passwd

**Разделитель полей на выходе** задается переменной `OFS` (Output Field Separator), по умолчанию пробел. Если вы меняете `OFS`, он влияет на то, как печатаются поля через запятую в `print`.

**Пример 8: изменение выходного разделителя**

bash

awk 'BEGIN { FS = ":"; OFS = ";" } { print $1, $3 }' /etc/passwd

Теперь между полями будет стоять `;`.

## 5. Встроенные переменные

AWK предоставляет множество предопределенных переменных. Наиболее важные:

|Переменная|Описание|
|---|---|
|`$0`|Текущая строка целиком|
|`$1`...`$N`|Отдельные поля|
|`NF`|Number of Fields — количество полей в текущей строке|
|`NR`|Number of Records — номер текущей строки (счетчик обработанных записей)|
|`FNR`|File Number of Records — номер строки внутри текущего файла (сбрасывается для каждого нового файла)|
|`FS`|Field Separator (входной)|
|`OFS`|Output Field Separator|
|`RS`|Record Separator (по умолчанию символ новой строки)|
|`ORS`|Output Record Separator (по умолчанию символ новой строки)|
|`FILENAME`|Имя текущего обрабатываемого файла|
|`ARGC`|Количество аргументов командной строки|
|`ARGV`|Массив аргументов командной строки|
|`ENVIRON`|Массив переменных окружения|

**Пример 9: использование NR и NF**

bash

awk '{ print "Строка " NR " содержит " NF " полей" }' /etc/passwd

**Пример 10: печать только строк, где больше 5 полей**

bash

awk 'NF > 5' /etc/passwd

(Здесь действие опущено, значит выполняется `print $0` для строк, удовлетворяющих условию.)

**Пример 11: использование FNR для обработки нескольких файлов**

bash

awk '{ print FILENAME, FNR, $0 }' file1 file2

## 6. Встроенные функции

AWK имеет множество встроенных функций для работы со строками, числами, временем и т.д.

### 6.1. Строковые функции

|Функция|Описание|
|---|---|
|`length([str])`|Возвращает длину строки (если аргумент опущен, длина текущей строки `$0`)|
|`substr(str, start [, len])`|Возвращает подстроку строки `str` начиная с позиции `start` длиной `len`|
|`index(str, substr)`|Возвращает позицию первого вхождения подстроки `substr` в `str` (начиная с 1) или 0|
|`match(str, regex)`|Ищет регулярное выражение `regex` в строке `str`, возвращает позицию начала или 0|
|`split(str, arr [, sep])`|Разбивает строку `str` на массив `arr` по разделителю `sep` (по умолчанию `FS`)|
|`sub(regex, repl [, str])`|Заменяет первое вхождение `regex` на `repl` в `str` (по умолчанию `$0`)|
|`gsub(regex, repl [, str])`|Глобальная замена всех вхождений `regex` на `repl`|
|`tolower(str)`|Приводит строку к нижнему регистру|
|`toupper(str)`|Приводит строку к верхнему регистру|

**Пример 12: использование строковых функций**

bash

awk '{ print tolower($1), length($0) }' /etc/passwd

**Пример 13: замена подстроки**

bash

awk '{ gsub(/bin/, "BIN"); print }' /etc/passwd

### 6.2. Математические функции

|Функция|Описание|
|---|---|
|`sin(x)`|Синус `x` (в радианах)|
|`cos(x)`|Косинус `x`|
|`atan2(y, x)`|Арктангенс `y/x` в радианах|
|`exp(x)`|Экспонента `e^x`|
|`log(x)`|Натуральный логарифм|
|`sqrt(x)`|Квадратный корень|
|`int(x)`|Целая часть числа (отбрасывание дробной части)|
|`rand()`|Случайное число от 0 до 1|
|`srand([x])`|Инициализация генератора случайных чисел (если `x` не задан, используется текущее время)|

**Пример 14: вычисление среднего арифметического**

bash

awk '{ sum += $1 } END { print "Среднее =", sum/NR }' numbers.txt

## 7. Операторы

### 7.1. Арифметические операторы

`+`, `-`, `*`, `/`, `%`, `^` (возведение в степень).

### 7.2. Операторы сравнения

`==`, `!=`, `<`, `<=`, `>`, `>=`.

### 7.3. Логические операторы

`&&` (И), `||` (ИЛИ), `!` (НЕ).

### 7.4. Операторы присваивания

`=`, `+=`, `-=`, `*=`, `/=`, `%=`, `^=`.

### 7.5. Специальные операторы

- `~` — сопоставление с регулярным выражением (проверка, содержит ли поле/строка шаблон).
    
- `!~` — отрицание сопоставления.
    
- `in` — проверка наличия элемента в массиве.
    

**Пример 15: использование операторов**

bash

awk '$3 >= 1000 && $3 < 2000' /etc/passwd

Вывод строк, где третье поле (UID) в диапазоне от 1000 до 1999.

**Пример 16: регулярное выражение**

bash

awk '$1 ~ /^root/' /etc/passwd

Поля `$1` начинается с "root".

## 8. Условные операторы и циклы

В AWK доступны стандартные конструкции:

- `if (условие) { ... } else { ... }`
    
- `while (условие) { ... }`
    
- `do { ... } while (условие)`
    
- `for (инициализация; условие; инкремент) { ... }`
    
- `for (переменная in массив) { ... }` — итерация по индексам массива.
    

Также есть операторы `break`, `continue`, `exit`.

**Пример 17: if-else**

bash

awk '{ if (NF > 5) print "Длинная строка"; else print "Короткая строка" }' file

**Пример 18: цикл while для суммирования чисел**

bash

awk '{ i=1; sum=0; while (i<=NF) { sum += $i; i++ } print sum }' numbers

**Пример 19: цикл for для обработки полей**

bash

awk '{ for (i=1; i<=NF; i++) print "Поле " i ": " $i }' file

## 9. Массивы

AWK поддерживает ассоциативные массивы (индексы могут быть строками). Индексы всегда являются строками, даже если вы указываете числа.

**Пример 20: подсчет частоты слов**

bash

awk '{ for (i=1; i<=NF; i++) count[$i]++ } END { for (word in count) print word, count[word] }' file.txt

**Пример 21: проверка наличия ключа**

bash

awk 'BEGIN { arr["a"]=1; if ("a" in arr) print "Есть" }'

**Пример 22: удаление элемента массива**

bash

delete arr["a"]

## 10. Пользовательские функции

В AWK можно определять собственные функции с помощью ключевого слова `function`.

**Синтаксис:**

awk

function имя_функции(параметры) {
    тело_функции
    return значение
}

Функции должны быть определены до их использования в программе, либо размещены в разделе `BEGIN`, либо в отдельном файле.

**Пример 23: определение и вызов функции**

bash

awk '
function square(x) {
    return x*x
}
{ print square($1) }
' numbers.txt

## 11. Форматированный вывод: printf

`printf` позволяет форматировать вывод аналогично C-функции `printf`.

**Синтаксис:** `printf "форматная_строка", выражение1, выражение2, ...`

Поддерживаемые спецификаторы: `%s`, `%d`, `%f`, `%e`, `%g`, `%x`, `%o` и модификаторы ширины и точности.

**Пример 24: форматирование**

bash

awk '{ printf "%-10s %6d\n", $1, $3 }' /etc/passwd

Поле `$1` выравнивается по левому краю на 10 символов, `$3` — по правому краю на 6 позиций.

**Пример 25: вывод с плавающей точкой**

bash

awk '{ printf "Среднее = %.2f\n", sum/NR }' data

## 12. Работа с несколькими файлами

AWK обрабатывает все переданные файлы по порядку. Вы можете использовать `FNR` для отслеживания номера записи внутри текущего файла, а `NR` — глобальный номер.

**Пример 26: обработка нескольких файлов с разделением**

bash

awk 'FNR==1 { print "=== Файл " FILENAME " ===" } { print }' file1 file2

## 13. Встроенные переменные окружения и управляющие переменные

- `ENVIRON["HOME"]` — доступ к переменной окружения.
    
- `ARGV` и `ARGC` позволяют обрабатывать аргументы командной строки как данные.
    

**Пример 27: доступ к окружению**

bash

awk 'BEGIN { print ENVIRON["USER"] }'

**Пример 28: обработка аргументов**

bash

awk 'BEGIN { for (i=1; i<ARGC; i++) print "Аргумент " i ": " ARGV[i] }' one two three

## 14. Запуск AWK-скриптов из файла

Поместите программу в файл, например `script.awk`, и выполните:

bash

awk -f script.awk input.txt

Структура файла может быть такой:

text

BEGIN { ... }
шаблон1 { ... }
шаблон2 { ... }
END { ... }

**Пример 29: файл скрипта `count.awk`**

awk

BEGIN { FS = ":"; total = 0 }
{ total++ }
END { print "Всего записей: " total }

Вызов: `awk -f count.awk /etc/passwd`

## 15. Дополнительные возможности GNU Awk (gawk)

GNU Awk добавляет много расширений:

- **Сети**: `print ... |& "/inet/tcp/0/host/port"`
    
- **Время**: `systime()` возвращает текущее время в секундах, `strftime()` форматирует дату.
    
- **Двусторонняя связь** с внешними программами.
    
- **Динамические библиотеки**.
    
- **Битовые операции** (`and`, `or`, `xor`, `compl`, `lshift`, `rshift`).
    

**Пример 30: время**

bash

awk 'BEGIN { print strftime("%Y-%m-%d %H:%M:%S") }'

## 16. Примеры комплексного использования

### 16.1. Вывод самых больших файлов в каталоге

bash

ls -l | awk '{ print $5, $9 }' | sort -nr | head -5

### 16.2. Анализ логов веб-сервера (пример формата Apache)

bash

awk '{ print $1, $7 }' access.log       # IP и URL
awk '{ count[$1]++ } END { for (ip in count) print ip, count[ip] }' access.log  # топ IP

### 16.3. Преобразование CSV в таблицу

bash

awk -F, 'BEGIN { OFS=" | " } { print $1, $2, $3 }' data.csv

### 16.4. Вычисление суммы по столбцу и процентов

bash

awk '{ sum += $2; arr[NR]=$2 } END { for (i=1; i<=NR; i++) printf "%3d%%\n", arr[i]/sum*100 }' data

### 16.5. Удаление дубликатов строк (сохраняя порядок)

bash

awk '!seen[$0]++' file

### 16.6. Замена разделителей в тексте

bash

awk '{ gsub(/,/, ":"); print }' file

### 16.7. Фильтрация строк по длине

bash

awk 'length($0) > 80' file

### 16.8. Суммирование чисел из каждого файла отдельно

bash

awk '{ sum[FILENAME] += $1 } END { for (f in sum) print f, sum[f] }' file1 file2 file3

## 17. Отладка и полезные приемы

- Используйте `print` для отладки.
    
- В gawk есть встроенный отладчик: запуск с `--debug`, команды `break`, `step`, `continue`, `print`.
    
- Вы можете использовать `system("команда")` для выполнения внешних команд (небезопасно, но иногда полезно).
    

**Пример 31: использование system**

bash

awk 'BEGIN { system("date") }'

## 18. Резюме

AWK — это мощный и лаконичный язык для обработки текста. Основные сферы применения:

- Быстрая извлечение данных из структурированных файлов.
    
- Анализ логов и статистика.
    
- Трансформация и конвертация форматов.
    
- Прототипирование обработки данных.
    

Ключевые концепции для запоминания:

- **Pattern-action** — основа.
    
- Поля (`$1`, ..., `$NF`) и разделители (`FS`, `OFS`).
    
- Встроенные переменные (`NR`, `NF`, `FILENAME`, `FNR`).
    
- Ассоциативные массивы.
    
- Встроенные функции для строк и чисел.
    

При большом объеме данных AWK обычно быстрее, чем эквивалентные скрипты на bash или Python благодаря своей оптимизированной реализации, но менее гибок для сложной логики.
